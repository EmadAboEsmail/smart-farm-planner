# 🌱 نظام تخطيط وإدارة المزارع الذكي (Smart Farm Planner)

تطبيق ويب تفاعلي حديث لتخطيط الأراضي الزراعية، توزيع الأشجار، تصميم شبكات الري، وحساب التكاليف التقديرية بشكل ديناميكي. تم بناء التطبيق باستخدام تقنيات الويب القياسية (Vanilla JS) مع التركيز على الأداء العالي وتجربة المستخدم السلسة (UI/UX).

## ✨ المميزات الرئيسية

### 🗺️ التخطيط والرسم
- **رسم ديناميكي:** توزيع تلقائي للأشجار بناءً على أبعاد الأرض ومسافات الزراعة.
- **تعديل حدود الأرض:** إمكانية سحب زوايا الأرض لتغيير شكلها ومساحتها.
- **التحكم بالمشهد:** تكبير (Zoom)، تحريك (Pan)، وتدوير الخريطة (Rotate).
- **وضع 3D:** زر لتحويل المنظور لرؤية ثلاثية الأبعاد.

### 🌳 إدارة الأشجار
- **تفاعل ذكي:** النقر على أي شجرة لتكبيرها وعرض بياناتها (رقم الصف، العمود).
- **إجراءات فردية:** إمكانية حذف شجرة محددة، صف كامل، أو عمود كامل.
- **تحريك الأشجار:** سحب وإفلات أي شجرة لتعديل مكانها يدوياً.

### 💧 نظام الري الذكي
- **أنماط متعددة:** دعم تمديد الخراطيم أفقياً (مع الصفوف) أو عمودياً.
- **التحكم بالإزاحة:** إمكانية إزاحة خط الأنبوب عن جذع الشجرة بمسافة محددة.
- **محاكاة الجريان:** عند تفعيل زر "الري"، تتحول الأنابيب للون الأزرق مع حركة انسيابية للمياه.
- **الوضع الافتراضي:** أنابيب سوداء متصلة وواضحة.

### 🏗️ العوائق والمباني
- **إضافة كائنات:** إضافة (مباني 🏠، طرق 🛣️، آبار مياه 💧).
- **التفاعل:** سحب وإفلات العوائق، وتغيير أبعادها (الطول والعرض) عبر بطاقة تحكم خاصة.
- **المنطق الذكي:** النظام يمنع تلقائياً زراعة أي شجرة تقع في مساحة المبنى أو الطريق.

### 💰 الحسابات والإحصائيات
- **لوحة معلومات:** عرض فوري للمساحة الإجمالية، عدد الأشجار، والكثافة الزراعية.
- **حاسبة التكاليف:** إدخال سعر الشتلة وسعر متر الخرطوم لحساب التكلفة الإجمالية للمشروع فورياً.

### 🎨 واجهة المستخدم (UI/UX)
- **تصميم زجاجي (Glassmorphism):** واجهة عصرية شبه شفافة.
- **الوضع الليلي:** دعم كامل للثيم الداكن لراحة العين.
- **تجاوب كامل:** يعمل بسلاسة على أجهزة الكمبيوتر والهواتف الذكية (Touch Support).

---

## 🛠️ التقنيات المستخدمة

- **Languges:** HTML5, CSS3, JavaScript (ES6 Modules).
- **Rendering:** SVG (Scalable Vector Graphics) للأداء العالي والدقة.
- **Styling:** CSS Variables, Flexbox, Grid, Animations.
- **Icons:** FontAwesome 6.
- **Fonts:** خط "Cairo" من Google Fonts.

---

## 📂 هيكلية المشروع

تم اتباع مبدأ **فصل المسؤوليات (Separation of Concerns)** لتسهيل الصيانة والتطوير:

```text
/
├── index.html       # الهيكل الأساسي للصفحة
├── style.css        # التنسيقات (Glassmorphism, Animations)
└── js/
    ├── main.js      # نقطة الدخول والربط العام
    ├── state.js     # مخزن البيانات (State Management)
    ├── render.js    # منطق الرسم (SVG generation)
    ├── events.js    # التعامل مع الماوس واللمس (Event Handlers)
    ├── ui.js        # التلاعب بعناصر الواجهة (DOM Manipulation)
    ├── utils.js     # دوال مساعدة وحسابات رياضية
    └── storage.js   # حفظ واسترجاع البيانات (LocalStorage)
إليك ملف **README.md** احترافي وشامل باللغة العربية، يوثق كافة الميزات التي قمنا ببنائها، ويشرح هيكلية المشروع وطريقة الاستخدام.

بما أن المشروع لا يعتمد على أطر عمل (Frameworks) أو أدوات بناء معقدة، يمكنك تشغيله بسهولة:

2.  يفضل استخدام **Local Server** لتجنب مشاكل سياسات المتصفح (CORS) مع ملفات ES6 Modules.
    *   إذا كنت تستخدم VS Code، قم بتثبيت إضافة **Live Server**.
    *   اضغط كليك يمين على `index.html` واختار **Open with Live Server**.

4.  **الري:** اضغط زر 💧 لمشاهدة محاكاة تدفق المياه.
5.  **التكلفة:** اضغط على أيقونة "العملات" في الأعلى وأدخل الأسعار لتقدير الميزانية.
6.  **التصدير:** استخدم زر الكاميرا 📷 لحفظ المخطط كملف SVG.
