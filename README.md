# 🌱 نماء (Namaa) - نظام تخطيط وإدارة المزارع الذكي

**نماء** هو تطبيق ويب متطور وسريع لتخطيط المزارع وتصميم شبكات الري وحساب التكاليف التقديرية. تم تصميمه ليعمل بالكامل داخل المتصفح دون الحاجة إلى تثبيت برامج معقدة، مع التركيز على سهولة الاستخدام ودقة البيانات.

## ✨ المميزات الرئيسية

يوفر التطبيق مجموعة أدوات متكاملة للمهندس الزراعي والمستثمر:

- **🎨 تخطيط تفاعلي:** رسم حدود الأرض وتعديل أبعادها بالسحب والإفلات.
- **🌳 توزيع ذكي:** خوارزميات لحساب عدد الأشجار بناءً على مسافات الزراعة ونوع المحصول.
- **💰 دراسة جدوى فورية:** حساب التكلفة التقديرية (شتلات + خراطيم ري) بشكل لحظي.
- **🧊 منظور ثلاثي الأبعاد (3D):** معاينة شكل المزرعة بمنظور واقعي.
- **📊 تصدير البيانات:**
  - تصدير المخطط كصورة عالية الدقة (`SVG`).
  - تصدير إحداثيات الأشجار لملف إكسل (`CSV`) لاستخدامها في أجهزة المساحة (GPS).
- **🛠️ أدوات مساعدة:**
  - نظام تراجع (Undo) لحفظ الخطوات.
  - وضع ليلي (Dark Mode) لراحة العين.
  - محاكاة نظام الري.

## 🚀 طريقة التشغيل

المشروع مصمم ليكون بسيطاً للغاية (Plug & Play). لا حاجة لتثبيت `Node.js` أو أي بيئة خادم.

1.  قم بتحميل ملفات المشروع.
2.  تأكد من وجود الملفات الثلاثة في نفس المجلد:
    - `index.html`
    - `style.css`
    - `script.js`
3.  افتح ملف `index.html` باستخدام أي متصفح حديث (Chrome, Edge, Firefox).

> **ملاحظة:** يحتاج التطبيق إلى اتصال بالإنترنت فقط لتحميل مكتبة الأيقونات (Phosphor Icons) والخطوط (Google Fonts).

## 📂 هيكلية المشروع

تم تصميم الكود بمعيارية عالية لسهولة الصيانة والتطوير:

```text

├── style.css       # التنسيقات، الألوان، والرسوم المتحركة
├── script.js       # المنطق البرمجي (مقسم إلى وحدات: State, UI, Render, etc.)
└── README.md       # ملف التوثيق
```
